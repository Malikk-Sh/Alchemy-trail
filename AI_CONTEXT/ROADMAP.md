# Roadmap

Work in vertical slices. Do not skip ahead for content volume.

## Phase 0 — Foundation

Deliver project structure, TypeScript, static build, screen manager, design tokens, save skeleton/test runner/content-validation foundations. Gate: title screen loads on mobile and CI passes.

Current state: **code and CI verified; mobile visual smoke check pending.**

## Phase 1 — Brewing vertical slice

One ingredient, mortar/grind, cauldron, Atlas, stir, one resonance node, Infuse, bottle. Gate: one real potion can be created from scratch.

## Phase 2 — Customer sale loop

Customer data, request evaluator, shop screen, offer/evaluate, sale/coins, next customer, day state, IndexedDB/reload persistence, first tutorial flow. Gate: complete economic loop.

## Phase 3 — Content foundation

Expand to roughly 8 ingredients and 8 effects; trader, day end, journal, recipe save, settings, sound, content validation growth, initial smoke tests/PWA work. Gate: MVP candidate structure.

## Phase 4 — MVP polish

Tutorial, robust save, settings/accessibility, audio, mobile fixes, PWA basics, E2E. Gate: playable/reloadable MVP on target mobile viewports.

## Phase 5 — Progression

Reputation, upgrades, recipe mastery, more Atlas regions/customers.

## Phase 6 — Garden/world systems

Garden, world events, commissions, advanced traders.

## Phase 7 — v1 polish/content

35+ ingredients, 30+ effects, content variety, final original assets, balancing, performance, accessibility, offline/PWA quality, no critical blockers.
